# TYPE-04：竖排句子与实物穿插

参考：`media/vertical-letter-scenes.png`。四格静态图共同特征是：粗体浅色短句形成窄竖向文字列，与建筑、玻璃杯、桌椅或手持物体重叠；不是找单词网格，也不是 FLOWING 的环绕字母。

## 排版结构

- 一个短句，通常 5–8 个词组 / 行，居中形成竖向节奏。英文仍然每个单词横写，不把每个字母机械竖排成一列。
- 文案可读且与场景有关，例如 `Listen / to / the / ocean’s / whisper`。可替换语言与句子，不复制参考的全部文案。
- 起点：文字列宽约 25%–45% 画幅、高约 40%–65% 画幅；沿主体中心或有效留白调整，不强制固定比例。
- 粗体系统无衬线，白 / 米白 / 淡冷灰，适当紧凑行距。颜色、字号和位置服务底图对比度；不能小到像标签，也不默认加卡片底板。

## 实物与文字的关系

先定义主体外框、中心轴、轮廓遮罩。选择明确的前后关系：不透明实物遮住后方文字，或文字覆于实物前方；透明杯可降低后方字母的对比度，保留透视感。不能用方形低透明块冒充杯体遮罩。

为了句子读得懂，应有完整前景阅读阶段；不要让关键字在整个循环里都消失在物体后方。前后层的转换属于动效设计，透明玻璃的示例处理是艺术化层次表达，不声称真实光学折射。

## 文字放大循环（当前默认）

静态参考不提供运动证据。用户修订要求：不要最后消散，字母简单放大即可。

- 完整句子从首帧到尾帧持续可见，不从两侧飞入，不旋转散开，也不淡出复位。
- 以单词 / 行为单位保持字距和基线，相邻行错开约 0.4 秒，在原位从 100% 平滑放大至约 118%，再回落到 100%。幅度按画面调整，避免相邻行碰撞。
- 每行使用固定中心为缩放轴；底图、文字列位置、透明杯遮罩与透明度保持不变。尾首回到相同完整排版，无消失帧。
- 当前示例为 6 秒循环，约 2.4 秒完成每行放大回落，余下时间停留阅读。放大不是拉开字距或逐帧重排。
- 仅在用户另外选择时采用聚拢、散开等更复杂时序，不能将上一版消散动作留作默认退场。

## 验收

390px 看完整句子，不靠放大拼读；检查四帧能看见放大与回落，且文字始终完整可见；主体遮罩不漂，关键字有完整阅读时刻；首尾衔接时背景不跳动。完整导出后检查实际播放或带时间的连续帧，静态关键帧不足以验证动作。
