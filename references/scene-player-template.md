# UI-01A：人物前后穿插的 iOS 音乐卡

参考：`media/music-cards.jpg`。此次上传的第一张拼图已在库中；新增的是明确的子模板和示范成品，不重复计入另一张参考。

## 核心关系与动态适配

- 浅灰 / 中性灰磨砂卡片，圆角与半透明叠层，使用背景模糊体现玻璃质感；无大面积主题染色。
- 优先横向音乐 / 播客卡，参考起点为宽 70%–85% 画幅、宽高比约 2.5–3.2。根据照片留白与主体调整，不要求 1:1 或固定坐标。
- 主要位于人物头肩附近的后景。人物头发、脸、肩或手作为前景遮挡一部分卡片，使 UI 像进入真实场景。
- 遮挡不能吃掉全部核心信息。封面、标题和至少一组播放控制仍应在手机尺寸下清楚辨认。
- 按拼图的四种关系选择：头肩前景的横卡；人物后方播客横卡；前景大竖卡；脚下透视卡。不将其中一个位置当作通用强制布局。

## 素材、层次与锚点

底图 → 卡片背景取样模糊 → 灰白玻璃层 → 封面 / 标题 / 进度 / 控制 → 主体前景遮罩。

使用同一底图的准确前景遮罩恢复发丝与轮廓，不能随意画一个椭圆洞或叠一张位置不一致的人像。封面用原创图形或有权限素材；不把别人的封面、歌手和歌名视为默认内容。展示文案可为场景化虚构曲目，但不声称正在真实播放歌曲。

## 动效设计

静态参考只说明构图和材质，没有可验证时序。示范采用原创 6 秒循环：卡片短暂淡入 → 进度点明显向前推进、音频小柱起伏 → 留出阅读时间 → 卡片短暂淡出复位。人物、卡片位置、字体和遮罩固定，不让整幅照片晃动。

其他适配可以设计播放/暂停切换或封面变化，但一条主动作就足够；不需要每帧改变所有控件。输出默认静音。

## 验收

- 对照 `music-cards.jpg` 检查灰色材质、比例与信息层级；390px 缩图能读到标题并辨认控件。
- 前景轮廓没有灰边 / 缺口，卡片内容被遮挡的范围有意且稳定。
- 检查开场、进入、停留、退出帧，进度确实变化；循环复位时不出现底图或人像跳动。
- 示例中采用的运动是新设计，不能标成复刻原参考视频动作。
