# 默认效果库：先复用，再适配

先选择与照片适合的 3 套作为文字方案，待用户确定后，仅为所选方案在 brief 中记下编号与参考路径并开始生成。以下是用户提供并已练过的方向，不表示用户认可代理每一版成品。已有错误优先参见 casebook。

| 编号 | 效果与参考 | 应继承的样式和动作 | 允许局部适配 |
| --- | --- | --- | --- |
| UI-01 | 大型音乐/播客播放器，media/music-cards.jpg | iOS 中性灰磨砂、清楚的封面/曲名/进度/控制层级；适当大；人物或实物可在前景遮挡 | 封面、文案、摆位、进度/播放状态；主面板不自由换色 |
| UI-01A | 人物前后穿插播放器，media/music-cards.jpg；[具体模板](scene-player-template.md) | 中性灰磨砂横卡与人物前景遮挡、清楚封面与控制；原创进度 / 波形循环 | 按主体调整卡片位置和大小，不硬套同一坐标 |
| UI-02 | 专注/心情胶囊，media/focus-modes.jpg | 灰黑半透明与白色选中态；圆角、系统排版；依次切换状态 | 与阅读/独处/休息相符的标签，组的位置和适当大小 |
| UI-03 | 地图落地，media/maps-in-scene.jpg | 地图本身的正常配色，透视卡片与脚/鞋遮挡；地点/路线/头像 | 地点、路线、落位；不把地图改成装饰色大色块 |
| COL-01 | 粉色页眉/耳机杯，media/pink-music.mp4 | 大粉色区域、深色星星、跨界播放器、白色手绘耳机/连线；粉星明显飘落 | 当前饮料、封面、短文案、尺寸与锚点；沿用既有粉色框架 |
| COL-02 | 黄色分屏/音乐，media/yellow-music.mp4；[结构模板](yellow-split-template.md) | 以 half-50 / source-29 为起点动态排版；白色流动乐谱、杯侧手绘小播放器、双耳罩→Y 节点→播放器底部连线 | 当前物体、原创封面、短文案；按照片调整比例与摆位，保留结构联系，不混入另一类 UI |
| TYPE-01 | 找单词，media/word-search.mp4 | 均匀小字组成醒目整体、手绘细圈、字母散落；先确认实际样片和遮挡 | 与主体有关的目标词、网格位置、圈词颜色沿用参考 |
| TYPE-02 | 数字连线杯，media/numbered-cup.mp4 | 开场全数字，线到才转英文；对称杯形；细白线和稀疏标签 | 合适语句与锚点，时长按动作可读性调整 |
| TYPE-03 | FLOWING，media/flowing-letters.mp4 | 独立字母的真实漂移/展开，气泡；不擅自环绕、不擅自加杯后遮挡 | 照片锚点与轨迹尺度，须逐帧分析 |
| TYPE-04 | 竖排句子 / 字母穿插，media/vertical-letter-scenes.png；[具体模板](vertical-letter-template.md) | 粗体浅色窄文字列与实物前后交叠；字母错开聚拢、停留、散开 | 文案、字位、遮罩与轨迹适配新照片，不冒称静态参考提供了运动时序 |
| DOODLE-01 | 咖啡云朵/小人，media/cloud-gymnast.mp4 | 铅笔云、落星、小人在杯沿的接触摆动、逐字短句 | 素材原创但风格、锚点和动作继承；尺寸确保明显 |
| DOODLE-02 | 雨滴/五线谱/耳机线，media/music-rain.mp4 | 原照片不加彩色页眉；白色波动五线谱与流动音符、雨字与蓝色雨滴、青色耳机线、播放器和逐字短句 | 根据物体与留白选择原有元素，继承线条、配色和运动，避免加成另一套页眉模板 |


七段视频和四张参考拼图均已随包附带，来源见 [media-index.md](media-index.md)。如果文件损坏或缺失，不要假装已经看过。给出 3 个适配的文字方案即可，不倾倒整个效果库，不提前生成画面；从整个效果库按照片筛选，不固定给播放器、胶囊、找单词三项。若用户明确指定一个效果并要求直接生成，遵从其选择。

不要默认另造 MENTAL BATTERY 等新仪表盘类型。若用户明确要求这种方向，则其 UI 也先采用灰色 iOS 材质；苹果等物体颜色只作小面积状态强调。用户要求完全新风格时才扩大探索。
