# 运动分析与动作设计

## 参考视频拆解

先看完整比例的接触表，再针对模糊处读取带时间的单帧。记录：

1. 初始状态，包括尚未启动的数字、占位、文字、线条。
2. 每个主元素的位置、尺度、朝向、透明度如何变化。
3. 元素有没有共同路径、独立路径、前后遮挡，还是只在屏幕平面移动。
4. 触发时刻、动作终点、完成状态停留多久，以及如何回到开头。

跟踪位置时用物体锚点消除相机运动。至少取三到五个时刻；不能只用一个起点和一个终点推断圆周运动。如果动作只看到一小段，保留无法确定的部分，不宣称完整轨迹已知。

静态拼图只能确定布局和材质，无法证明动画、速度或循环方式。

## 动作由事件决定

用“起始状态 → 触发 → 主要变化 → 可读停留 → 重置”描述。并非每个作品都必须经过五个显式阶段，但涉及因果的变化必须正确。

- 数字与线条：初始化全数字；根据线的实际绘制进度到达对应点才替换为英文。注意进度为零不应提前显示第一个词。
- 开关模式：选中状态、背景、图标和文字同步变化，给用户看清被选中内容的时间。
- 播放器：播放/暂停与进度条状态一致；存在 UI 不代表必须使用真实歌曲。
- 挂在物体上的角色：接触点是旋转或动作锚点，不能整个人漂离物体。
- 飘落物：明确产生区域、运动范围、消失位置和画面边缘处理。
- 独立字母：可各自漂移、展开、聚拢或沿路径运动。不要默认环绕；也不要默认必须被主体遮挡。

## 明显而协调

动效明显可以来自位移、尺度、状态切换、线条推进或构图变化，不必同时使用。先保证一个主要变化可见，再添加辅助运动。

方向、速度、频率要服务情绪。安静场景仍可有大而清楚的 UI 切换；活泼场景也不应让所有元素随机乱动。不能用极淡透明度掩盖缺乏设计的运动。

## 循环

可选周期路径、首尾同态、渐隐重置、匹配转场或往返播放；按故事选择。往返不适合所有动作，例如文字倒着打出可能不自然。对周期路径，位置、朝向、透明度、纹理和辅助元素都应检查尾首衔接。不能只让主元素闭合而忽略进度条跳变或气泡突现。

接触表用于分析和定位问题，不能替代所有播放判断。能播放时看实际导出；无法播放时比较有时间标记的连续帧与首尾状态，明确检查范围。
