# 用户参考与已发生的纠正

以下来自 2026-11-05 的实际创作对话。区分“用户提供的参考”“用户明确纠正”与“代理自己的解释”。代理交付过不等于用户认可，不以此给案例打成功标签。

## 用户明确反馈

- **风格失败（最新、优先执行）**：用户指出苹果“MENTAL BATTERY”卡片的黄绿框和甜品模式控件配色不符合其 INS 审美。苹果卡应接近既有音乐参考的灰色磨砂；UI 应遵循参考里的 iOS 设计。用户要求优先套用之前提供并练过的效果，减少完全自由创新。后续不能把“配色呼应苹果/甜品”作为改造 UI 色系的理由。参考框架内的文案、布局、遮挡与动作适配仍可有创意。

- **尺度失败**：用户评价几版原创作品“都太小、太不明显”。对应尝试包括银杏蝴蝶、脚印变音符等。创意提案即使与照片相关，也不代表画面存在感足够；这两项必须分别检查。
- **时序失败**：杯形线条案例被指出不对称，且应先显示数字，白线到达后才变英文。修复应覆盖形状和触发状态，不只是改文案。
- **运动理解失败**：柠檬水“FLOWING”案例被指出不是直接环绕。应逐帧观察各字母独立的漂移和展开，不套椭圆轨道，不擅自加杯后遮挡。
- **数量与流程（最新规则）**：早前用户追问为什么做三版，后来明确更新为“先基于现有效果给 3 个文字方案，用户确定再生成”。当前默认给 3 个文字方案，等待选择后才制作一版；不先生成三张预览或三个成品。新要求覆盖早期默认自主选一版的规则。

## 静态参考：大元素与场景关系

- [专注模式胶囊](media/focus-modes.jpg)：占据明显构图面积的控件组；亮暗选中态表达 selfcare / me time / peace 等情绪，与阅读、休息照片相连。
- [播放器](media/music-cards.jpg)：大型卡片、明确可读的 UI；人挡住卡片，卡片包住镜中照片，或鞋踩在倾斜卡片上。尺度和遮挡都参与叙事。
- [地图](media/maps-in-scene.jpg)：大地图按地面透视放置，鞋子位于前景；地点、头像、气泡组成出行故事。

以上都是静态拼图，不能由此声称其动画时序。

## 短视频参考

- [找单词](media/word-search.mp4)：字母网格、圈词、散落；观察前景杯子的遮挡与动作先后。
- [云朵小人](media/cloud-gymnast.mp4)：云朵落星、固定杯沿接触点的小人摆动、打字短句。
- [音乐雨滴耳机](media/music-rain.mp4)：原图上的流动五线谱、雨滴、耳机线和播放器，没有粉/黄色页眉。是独立的已练效果，不应漏列或与彩色页眉合并。

- [数字变单词的杯形线条](media/numbered-cup.mp4)：先抽帧确认初始状态与每个转词时刻。用镜像几何保证对称，用线进度统一驱动文字切换。
- [FLOWING 字母与气泡](media/flowing-letters.mp4)：跟踪独立字母；注意消除相机运动，不能概括成圆周环绕。
- [粉色页眉与耳机杯](media/pink-music.mp4)：大色块页眉、跨越分界线的播放器、贴合杯子的耳机、明显飘落的星星。大小、跨层、配色作为整体设计。
- [黄色页眉与五线谱](media/yellow-music.mp4)：醒目的颜色区域与大幅波动的五线谱；播放器和线缆把图形与照片联系起来。不要只复制一串微小音符。

这些媒体仅作用户提供的审美与动作参考，不是可直接发出的成品底图或贴纸素材。制作新作品时使用用户当前授权的图片、原创资产和适合任务的内容。
