# COL-02：黄色分屏音乐模板

适用：用户选择黄色音乐分屏，或指明“一半一半”的既有音乐效果。此文件只约束 COL-02，不覆盖灰色 iOS 大播放器、粉色页眉、地图等其他家族。

## 先选构图版本，不能混用

- **half-50（用户说“一半一半”时）**：黄色区域为整幅高度的 50%，照片为下方 50%。分界线 y=0.50H，容差 ±0.01H；不能变成 20%–30% 顶部横幅。
- **source-29（用户明确要包内黄色视频原构图时）**：以 `media/yellow-music.mp4` 为准，当前包内 480×640 样片的黄色区域约为上方 29%，照片约 71%；分界线 y≈0.29H，容差 ±0.015H。
- “一半一半”是用户指定的构图适配版本，**不是声称原视频恰好 50/50**。尚未选择时，在文字方案中直接写清推荐版本与比例；用户选定后不另加确认环节。
- 用户仅泛称“黄色分屏”且未指定版本时，文字方案写明 half-50；不能默默以 source-29 或自由页眉比例实现。

比例定义使用完整成品画布，不能以某个裁切区域、截图或播放器高度充当分母。保留源照片；需要缩放置于照片区时先利用允许的构图空间。明显裁掉手、杯口、杯底或重绘背景不属于默认适配。无法同时满足时，在提案说明布局限制，不靠破坏照片硬套。

## 坐标与定位

画布宽 W、高 H，原点左上。黄色区域底边为 S，照片区高度 P=H−S；照片区内 y 坐标写作 `S+vP`。下表为**构图目标值与容差**，来自包内黄色样片的近似拆解及 half-50 的适配设计，不能当作逐像素测量真值。

| 元素 | source-29 | half-50 |
| --- | --- | --- |
| 黄色分区 | 全宽，S=0.29H | 全宽，S=0.50H |
| 乐谱可见运动区 | x=0–W；y≈0.03H–0.26H | x=0–W；y≈0.12H–0.42H |
| 杯子目标中心 x | 0.50W，容差 ±0.06W | 同左 |
| 杯子目标外框 | 左≈0.33W；上≈S+0.05P；宽≈0.35W；高≈0.55P | 左≈0.34W；上≈S+0.06P；宽≈0.31W；高不超过 0.70P |
| 播放器外框 | 左=0.735W；上=S+0.34P；宽=0.23W | 左=0.735W；上=S+0.34P；宽=0.23W |
| 播放器长宽比 | 高/宽≈1.36，容差 ±0.10 | 同左，不随照片区变矮而压扁 |
| 播放器位置容差 | x、y 各 ±0.025W/H；宽 ±0.02W | 同左 |
| 电缆最低点 | 约 S+0.82P，必须在画内 | 约 S+0.90P，必须在画内 |

源照片主体的位置不符合表格时，**先在方案中说明适配关系**：保留主体，播放器仍在杯子右侧，手绘耳机随杯子锚定。获选的具体布局写入项目，不能渲染时临时把播放器换到左上方。若右侧确无空间，提出另一个适合的既有效果或清楚标明“镜像适配”，不能交付后才解释布局变了。

对很宽或很长的画布，以上各框可能冲突；模板不得独立拉伸卡片或杯子。先检查框是否在画内、相互是否重叠；必要调整必须在选定布局中说明，保留分区比例、播放器在杯侧、耳机连接三项关系。

## 播放器：保留小型手绘卡，不换成大 iOS 面板

- 在**照片区、杯子的右侧**，完整落于照片区；不跨分界、不换到左上角。不遮杯口、手指和吸管。
- 轮廓为深色近黑底的小型竖卡，细白色略带手绘质感的外框；内部有近方形封面、细进度条、简洁播放控制。该分屏参考本身不是 UI-01 灰色磨砂播放器，不混用其外观。
- 封面使用独立插画/唱片封面式图形，黄色可以呼应上方。不要把底图同一杯咖啡再裁一遍作为默认封面，不复制第三方专辑画面。
- 不擅自增大曲名区、添加长副标题或多层控件。390px 宽时优先识别“封面＋播放控制”；需要强调尺度时放大整个有空间关系的音乐组，不能只把卡片变成另一种大面板。
- 卡片宽度、外框、控制位置在动画中固定。实际可读性不通过时回到静帧布局修正，不在某些帧忽大忽小。

## 杯子戴耳机：四个必须成立的连接

先从本次照片读取杯子左右轮廓与杯沿，定义杯体框 `(cx, cy, cw, ch)`，不可复制上一张照片的像素点。

1. **左右耳罩**：位于杯体两侧上部，中心大致为 `(cx, cy+0.23ch)` 与 `(cx+cw, cy+0.23ch)`；根据杯形贴合边缘。耳罩直径约 0.10–0.14cw。左右都必须能辨认为耳机组成部分，不能用两个漂浮星星代替两只耳罩。
2. **包裹与遮挡**：细浅黄色耳机线由两侧沿杯体朝下会合，表现耳机“戴在杯子上”。需要头梁时贴合杯沿，位于杯子后面的部分用遮罩挡住；不强加包内样片没有的大号拱形头梁。
3. **Y 形汇合**：两支耳机线分别从耳罩真实连接处出发，在杯体下部前方约 `(cx+0.50cw, cy+0.90ch)` 汇合，再接出一根白色主线。线不能从杯盖任意一点或杯外空气起笔。
4. **播放器插口**：主线终点固定于播放器底边中心；形成垂落的 U 形，中间最多一个小回环。不能只画“播放器拉一根线到杯边”，省掉双耳罩与 Y 形结构。

杯体框为贴合基准，不是要求重绘或对称化真实杯子。星星可以放在耳罩旁作辅助，但不能掩盖连接点。源物体不是杯子时，在方案里明确接触方式，不能假称其已有杯沿。

## 黄色区域、乐谱与文字

- 黄色保持整块连续区域，照片不透上来；淡纸纹/颗粒可保留。不要用渐变将分界抹掉。
- 白色五线谱跨全宽形成大幅波浪，主要运动始终在黄色区。音符按谱线轨迹出现/流动，不只是在顶部放一排静态大音符。
- 乐谱线在 390px 预览可辨，避免糊成发光色带。音符、星点为辅助层，不能盖住所有留白。
- 短句位置沿用照片区的边缘留白，字数简短；不自行加 `VOL.01`、栏目名和多组海报标题。

## 固定层与可动层

**固定**：分界线、照片、杯子、耳罩、Y 形连接点、播放器外框、封面与文字版式。

**可动**：谱线相位、音符沿谱移动/出现、进度点、少量星点闪现、短句的参考式显现。电缆中段可轻摆，但两端与 Y 形节点固定。不能以整幅照片晃动替代主动作。

读取样片实际时序；包内视频约 3 秒，不把任意 6–8 秒模板称为原样复刻。若改为更长循环，在制作约束注明动作如何扩展。开场/中段/峰值/结束至少四帧检查乐谱变化；衔接尾首，不让固定层跳动。

## 制作记录与验收

在静帧前记录：`variant`、`split_y/H`、`player_box`、`cup_box`、左右耳罩锚点、Y 形节点、播放器插口、线缆路径、封面来源、参考采样时间。所有坐标说明单位；布局和动画共用同一份参数。

检查顺序：

1. 分界在选定比例内；全图缩到 390px，第一眼仍是选定的上下分屏构图。
2. 卡片在杯右侧、尺寸与纵横比正确；没有重复咖啡照片封面、额外标题区或替换成灰色大 UI。
3. 两只耳罩贴杯，双支线汇合，白线从 Y 节点到播放器底部，前后遮挡成立。
4. 主动效在黄色区清楚可见；四帧中耳罩、插口和分界坐标不漂移，只有允许的参数变化。
5. 并排比较本次参考截图与关键帧；将“结构符合”与“颜色相似”分开记录。

任一关键结构不符合就修该层，不以“已有黄色、音符和播放器”判为通过。此模板属于规格更新；未重新渲染并逐项查看前，不声称它已保证成品效果。
