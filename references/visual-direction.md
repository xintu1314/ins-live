# 视觉方向与尺度

## 优先级：参考样式高于自选配色

默认先从 [effect-library.md](effect-library.md) 选择已练效果，继承其配色、材质、布局和运动。用户明确纠正：苹果电量卡的黄绿框不符合其 INS 风格，应接近之前音乐播放器的灰色 iOS 磨砂卡。甜品开关的奶油粉配色也不能仅凭照片颜色自由发挥。

对于 UI，优先中性灰磨砂/黑白选中态、系统无衬线、圆角、清楚层级和常见 iOS 控件语义；使用 `../assets/ui-tokens.json` 的近似设计值。状态色小面积使用。模板本来有粉/黄色页眉、地图颜色或封面色时保留，不能一概灰化。未经明确要求，不另造一套彩色 UI。

## 主设计要进入构图

“有氛围”不等于“装饰越小越好”。先辨认主照片内容，再决定新增设计是视觉主角、与主体平级，还是辅助。至少一个新增设计组应有明确存在感，不能所有内容都是小字、小点和细线。

对于播放器、地图、状态栏等卡片，画面宽度约 35%–75% 可作为起始探索范围；横贯画面的大色块和文字组也可成立。这是构图起点，不是所有素材必须遵守的比例。COL-02 黄色分屏的小型手绘播放器使用[专用结构模板](yellow-split-template.md)中的比例，不套用此通用卡片范围。手绘角色与动作组按观感判断，不强制卡片比例。

从开场或主要动作开始后的短时间内，观众应能看出设计重点，而不是必须等待全部播放并放大才发现。静帧主视觉、运动可见性分别检查。

## 可选视觉机制

| 机制 | 适合的照片关系 | 尺度与层次关键 |
| --- | --- | --- |
| 场景化播放器 | 听歌、独处、咖啡、穿搭 | 卡片可站在人物后面、落在地上、跨过拼贴边界；文字和控制可读 |
| 专注/心情模式 | 阅读、休息、工作、甜品 | 多层胶囊构成一个清楚的组，用选中状态讲变化；避免五个同样显眼的控件 |
| 脚下地图/路线 | 出行、街头、鞋子 | 按地面透视落位，脚与卡片相互遮挡；地点有语义 |
| 彩色页眉与图形跨层 | 手持物、食物、明亮主题 | 色块可占较大面积，但不能机械盖掉重要主体；主体、耳机、卡片跨边界建立联系 |
| 文字/路径事件 | 关键词、数字、线描形状 | 文字组形成主视觉；关键字大小、路径与触发顺序清晰 |
| 手绘角色/小故事 | 有明确锚点和互动对象 | 有足够大的角色与动作，身体接触点固定，运动方向合情境 |

这些机制用于选择适合当前照片的已有参考。默认保留选定参考框架，局部适配；只有用户明确要新方向时，才进行完全不同的组合与发明。

## 材质与字体

- UI 主材质遵循选定参考的中性灰，不从照片提取物体颜色来重新染整块控件。照片色可用于少量内容/强调；彩色页眉等明确参考保留原机制。
- 磨砂 UI 要体现透明、背景模糊、边缘和明暗层次；一个低透明灰矩形不等于玻璃质感。检查本地渲染能力后制作，不支持时用更诚实的实色或柔和材质。
- 手绘感依靠线条、纹理和轮廓，而非随意抖动所有元素。描线要在手机尺寸可见。
- 控件、地图、音乐播放器等适合清晰无衬线；手写字或衬线可以服务情绪。避免全部默认 Courier 小字。
- 文案与照片有关，简洁自然；不是每张图都要“Own the moment”、音乐或英文。

## 空间关系

前后景遮挡、接触点、投影与透视能把新增设计放进场景。按机制选择：

- 人物在播放器前：保留人物轮廓，不把半个控件错误遮掉。
- 地图在鞋下：卡片服从地面平面，鞋完整位于前景。
- 耳机戴在杯子上：头梁与耳罩尺寸对应杯身，线缆从真实连接处出发。
- 字母漂移：如果参考字母直接覆盖杯身，不要擅自改成杯后遮挡或绕杯旋转。

## 手机尺寸检查

将完整关键帧缩至 360–430 像素宽再看。检查主设计、文字层级、动作前后差异。太小就放大或重构布局；太乱就减少元素和层级，而不是把全部缩小。
