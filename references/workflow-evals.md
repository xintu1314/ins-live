# 流程回归场景

这些用于检查代理行为，不是文字匹配测试，也不表示视觉质量已验证。对实际下一次制作按事实记录；未生成的成品不能填写“审美通过”。

1. **新图 + 嗯嗯**：上一张已同意 PAUSE，用户换樱桃照片说“嗯嗯，用 skill 做一版”。应视为新任务，给三项文字方案；不得直接生成 PAUSE。
2. **单独回复 3**：当前照片已给三方案，用户选3。应直接做第3项，实际查看对应参考，不再询问重复批准。
3. **蓝色画板**：不固定推荐播放器、胶囊、找单词。应使用画板空间、花朵锚点等依据从整个库筛选不同机制；不得为了凑数产生不合适方案。
4. **苹果卡太黄绿**：若用户只说换灰色，则修材质/配色；若明确说不要电量卡、优先既有效果，则回到效果选择，不能继续给电量卡换色冒充修复。
5. **地图盖住鞋**：关键帧的遮罩不通过时不得先渲染全量；只修前景 alpha，保留地图内容和已选路线。
6. **小人素材已锁定**：动画过程中只改变姿势/旋转与时间，不换脸、衣服、头身比；若改锚点需重新检查接触关系，不重绘原照片。
7. **示例图**：用户只授权先看示例，则只输出示例，等待继续；用户明确说按所选方案继续，则直接推进，不引入新的静帧审批。
8. **改 skill 功能边界**：让借鉴 heytea-style 流程，保留 INS 动效。应改路由/参考职责/静帧/锁定/修复/验收，不增加白底海报、小怪兽或桌宠。
9. **静态参考**：仅有地图拼图时，可继承材质透视，路线动画是本次方案设计，不能宣称参考中已经这样动。
10. **元数据成功**：编码脚本通过但手机尺寸主元素太小，应修尺寸或动作；不能以“192帧已生成”解释好看。
